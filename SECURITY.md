# Security policy

## Supported versions

This branch is experimental and has no independent stable release yet. Report vulnerabilities against the latest build you can reproduce them on, identifying its commit or version. Once stable releases exist, support will focus on the latest stable version.

## Reporting a vulnerability

Use [GitHub private vulnerability reporting](https://github.com/abeachco-git/alter_ego/security/advisories/new) when enabled. If the form is unavailable, contact the maintainer through an agreed private channel before sharing any sensitive details. Do not open a public issue containing an exploitable vulnerability.

Include the affected version or commit, impact, affected component, reproduction steps and any safe diagnostic evidence. Redact API keys, account identifiers, character names and private data. Do not send your real API key, full account database, memory dump or unredacted backups.

Please allow time for investigation and coordinated disclosure. No fixed response deadline or bounty is promised.

If your GW2 API key may have been exposed, revoke it at [ArenaNet account management](https://account.guildwars2.com/applications), remove or replace the linked credential in Nexus options, and review the key's permissions.

For non-security problems, use the repository's ordinary issue tracker when enabled. See [Privacy](PRIVACY.md) for local storage and external services.
